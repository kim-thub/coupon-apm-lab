## 해석

위의 BLOCKED는 프로그램 기능 실패가 아니라 **실행을 시작하기 위한 환경 준비 단계가 차단된 상태**이다. 따라서 Java 코드의 실제 작동 여부는 확인되지 않았으며 AC01~AC11의 PASS를 주장하지 않는다. 소스/구성에 추가 변경이 생긴다면 다시 빌드·테스트를 실행하고 정확한 상태를 기록한다.
