# 공개 후보 검증 기록 · 2026-11-10

> 아래 본문은 공개 파일 정리 전후 검증 시점의 기록을 보존한다. 후속 공개 파일 커밋 기준의 최신 확인 결과는 문서 끝의 추가 기록을 참조한다.

이 기록은 승인된 공개 제외 파일을 기존 `main` 작업 트리에서 정리한 뒤의 보고서·증거·재현 검증이다. 정리 커밋은 `5ded03aafbe3975dac057928409cedde631f9ec9`이며 기존 이력을 유지했다. 별도 브랜치·원격 생성과 푸시는 하지 않았다.

## 원본 증거 백업

- 원본: 현재 `docs/evidence/` 전체, 1,457개 파일 / 1,039,681,848 bytes.
- 백업: 프로젝트 밖의 지속 보관 폴더 `Downloads/coupon-apm-lab-public-backup/`에 ZIP과 SHA-256 매니페스트를 복사했다.
- ZIP 크기: 129,065,867 bytes. SHA-256: `a12b4a01d7155af5ed506d9c58060dd27ab437d262870a43c80597df841068d8`.
- 복사된 매니페스트 SHA-256: `f138b837184d9a8882f806cd5421edc4e6f610cfea7dda183e4ad0ab83930658`.
- 복사본 ZIP의 SHA-256을 확인하고, ZIP 안 원본 **1,457개 파일 / 1,039,681,848 bytes 모두** 외부 매니페스트와 다시 대조했다. 내부·외부 매니페스트도 일치한다.
- 백업 무결성을 확인한 뒤 승인된 1,439개 현재 트리 파일을 제거했다. 원본 전체는 ZIP에 보존했다.

## AC07 자료 대조

각 배치의 `comparison.json`을 `all-runs.json`의 공식 6회 원자료에서 OFF/ON 중앙값과 변화율로 다시 계산했다. 네 배치의 유효성·목표·편차 판정 및 요약값이 일치했다.

| 구분 | 배치 | 유효성 | 목표 | 편차 | p95 변화 | 성공 TPS 감소 |
|---|---|---|---|---|---:|---:|
| 공식 1차 | `110901308de535` | VALID | PASS | REVIEW_REQUIRED | −16.04% | −0.88% |
| 공식 2차 | `1109034678e297` | VALID | FAIL | REVIEW_REQUIRED | +309.71% | +1.28% |
| 공식 3차 | `110923334c54bc` | VALID | PASS | REVIEW_REQUIRED | +1.11% | −0.41% |
| 추가 재측정 | `11092304b3ccfc` | VALID | PASS | REVIEW_REQUIRED | −9.21% | −0.49% |

공식 3차의 12개 실행마다 manifest와 warm-up/측정 validation 파일이 있으며, 이들을 공개용 경로 아래 원본 바이트 그대로 복사해 인덱스에 연결했다. 24개 phase 각각에 대해 요청 CSV 행 수, writer 기록 수, DB 커밋 목록 수, validation의 건수를 대조했고 모두 일치했다. 공식 3차 12개 run 원본 288개 파일의 SHA-256 목록을 별도 작성했다. 네 배치의 통합 인덱스에는 49개 실행이 있으며 1차 사전 실행의 무효 시도도 유효 실행과 별도 상태로 남겼다.

로깅 진단은 AC07 공식 배치가 아니다. 동기/비동기 p95 변화 +0.38%가 보고서와 원본 비교표에 일치한다. **2차 급등 원인은 미확정**으로 유지했다. 호스트 전체 CPU 계측은 없어 CPU 경합 원인을 증명하지 않는다.

## Gradle·Python 실행 결과

환경: macOS 26.6.2 arm64, Eclipse Temurin JDK 21.0.12.1, Gradle Wrapper 8.14.3, Docker 29.7.2. 실행 직전 기준 커밋은 `e200c914a6478b09411ac06a86ddbc0624daa9fb`다. 테스트 후 evidence 파일 4개가 새 테스트 실행값으로 쓰여, 승인 매니페스트와 해시가 일치하는 실행 전 증거 바이트로 복원했다.

## main Git 이력·공개 메타데이터 점검

- 현재 브랜치는 `main`, HEAD는 `5ded03aafbe3975dac057928409cedde631f9ec9`다. 기존 3개 커밋 위에 공개 제외 파일 삭제만 기록한 커밋 1개를 추가했다. 브랜치·remote 설정은 변경하지 않았다.
- main에서 도달 가능한 고유 blob은 330개, 비압축 합계 210,469,165 bytes다. Git pack은 101.53 MiB다. 5 MiB 이상인 개별 blob은 없고, 가장 큰 것은 AC07 1차의 `requests.csv` 4,816,753 bytes다. 따라서 현재 스냅샷에서 원본 실험 파일을 제거해도 기존 커밋 이력에서는 제거되지 않는다.
- main의 이력 blob을 대상으로 사용자 홈·임시 디렉터리의 절대경로와 흔한 credential 패턴을 검색했으며 main 이력에서 일치 항목은 없었다. 이는 패턴 검색 결과이지 모든 종류의 비밀정보를 보증하는 검사는 아니다.
- 기존 세 커밋은 같은 작성자 이름과 GitHub noreply 주소를 공개 메타데이터로 포함한다. 해당 신원 공개가 의도된 것인지 확인이 필요하다.
- `.git`에는 main 외 Codex 체크포인트 참조가 세 개 있다. 이들 참조의 일부 JSON에는 로컬 홈 경로가 있고 체크포인트 로그 blob은 최대 약 13.6 MB다. 이 데이터는 main에서 도달하지 않으며, main만 푸시하면 전송되지 않는다. 기존 참조는 변경하지 않았다.
- main 이력의 대용량 실험 자료를 공개 저장소에서 제거하려면 이력 재작성 또는 새 저장소/브랜치가 필요하지만, 현재 지시에서 금지되어 있어 수행하지 않았다. 파일 삭제를 승인하더라도 과거 버전은 main 이력에 남는다.

## 삭제 후보 참조 및 Git 인덱스 확인

- 최종 공개 후보 243개 문서의 상대 링크 65개를 검사했다. 링크 오류는 없고, README·보고서·스크립트가 최종 삭제 후보를 직접 참조하지 않는다. AC08의 `docs/evidence/lock-wait/README.md`는 보존 후보에 추가했고 내부 링크도 유효하다.
- `.env`, `.DS_Store`, 빌드·Gradle 캐시는 ignore 규칙에 걸리며 현재 Git 인덱스에 없다. 공개 매니페스트에도 들어 있지 않다. `.env.example`은 유지한다.
- 정리 전 인덱스는 AC07 원본 run 파일 300개, 210,036,926 bytes를 추적했다. 정리 커밋 후 현재 인덱스에서 해당 run 파일은 0개다. `.env`, `.DS_Store`, 빌드·Gradle 캐시도 인덱스와 공개 후보에 없다. `.env.example`은 유지한다.
- 승인된 1,439개 파일을 작업 트리에서 제거했다. 이 중 325개는 기존 인덱스 파일이라 커밋에 삭제로 기록됐고, 1,114개는 기존 비추적 파일이라 커밋 차이에는 나타나지 않는다. 계획·설계 문서 5개는 지속 보관 폴더에 복사했고 SHA-256을 재확인했다. 삭제 후보 CSV에는 백업 여부와 파일 해시를 표시했다.
- 요청대로 커밋에는 승인된 삭제만 스테이징했다. 공개 보고서·README 변경과 243개 공개 후보 매니페스트는 작업 트리에 유지했지만 정리 커밋에는 포함하지 않았다. 이 파일들을 포함하는 추가 커밋 전에는 현재 HEAD만으로 공개 후보 전체가 구성되지 않는다.

- AC01~AC11 각각에 검증 방법·결과·판정·한계를 기록했다. AC07 공식 세 배치와 추가 재측정, 별도 로깅 진단을 구분하고, 실패·편차·미확정 원인을 축소하지 않았다.
- 증거 링크는 보고서 마지막 절에 모았다. 링크 점검 결과와 공개 후보의 정확한 파일 목록·SHA-256은 별도 공개 파일 매니페스트에서 확인한다.

공개 후보 파일 목록과 각 파일의 크기·SHA-256은 [`public-file-manifest.csv`](../public-file-manifest.csv)에 있다. 현재 목록은 243개 파일이며, 공개 후보의 검증 보고서와 테스트 요약본도 포함한다. 자체 해시 순환을 피하기 위해 매니페스트 파일 자신만 목록에서 제외한다.

정리 커밋 `5ded03aafbe3975dac057928409cedde631f9ec9`의 부모는 원래 실험 커밋 `e200c914a6478b09411ac06a86ddbc0624daa9fb`다. 기존 이력을 보존했으므로 삭제된 원본의 과거 버전은 main 이력에 남는다. 원격 생성과 푸시는 하지 않았다.

## 후속 공개 파일 커밋 기준 최종 확인

- 공개 후보 확정 커밋은 `ad9ced26bed26830a50522fd27f9049254749934`이며, 앞선 검증 커밋 `5ded03aafbe3975dac057928409cedde631f9ec9`를 부모로 한다. 이 SHA는 보고서 작성 시점의 확정 커밋을 가리킨다.
- 위의 기존 검증 기록은 `5ded03a...` 시점의 스냅샷이다. 당시 “공개 후보가 아직 커밋되지 않았다”는 상태 및 그 시점의 HEAD 표기는 이력으로 유지한다. 후속 커밋에서 공개 후보 파일 243개를 추가·갱신했다.
- 이번 기록과 매니페스트 갱신 후 공개 후보 243개 모두 파일 크기와 SHA-256이 작업 트리 파일과 일치함을 재확인했다. 매니페스트 자신은 순환 해시를 피하기 위해 대조 대상에서 제외했다. 갱신된 매니페스트와 커밋 blob의 최종 대조는 아래 검증 기록 최신화 커밋에서 확인한다.
- 후속 커밋의 Gradle 단위 빌드는 11건, 통합 테스트는 PostgreSQL/Testcontainers 기반 12건 모두 통과했고, Python 테스트 6건도 통과했다. README·보고서의 65개 상대 링크, 공개 후보의 로컬 경로·비밀정보 패턴 검사는 오류 없이 끝났다.
- 기존 ADR과 `docs/report.md`·`docs/report.html`의 AC01~AC11 판정은 변경하지 않았다. AC07 공식 2차 `FAIL`, 네 배치의 `REVIEW_REQUIRED`, 2차 원인 미확정 기록도 그대로 유지했다.
- 정리 후속 커밋은 `ad9ced26bed26830a50522fd27f9049254749934`다. 이번 검증 기록 최신화 커밋은 이 커밋 위에 별도로 추가한다. 기존 `main` 이력을 유지하며 브랜치 생성·이력 재작성·원격 생성·푸시는 수행하지 않았다. LICENSE도 추가하지 않았다.
